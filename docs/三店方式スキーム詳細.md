# FanUp 三店方式スキーム詳細

## 概要

FanUpは「ファンクラブデビュー応援型クラウドファンディング」として、ファンからクリエイターへの支援金を資金決済法の規制対象外で流通させるため、三店方式（3エンティティ間接方式）を採用する。

ファンが購入するのは「ポイント」というデジタル財であり、クリエイターが受け取るのは「業務委託報酬」である。ファン→クリエイター間の直接的な資金移動は発生しない。

---

## エンティティ構成

### A社: FanUp（プラットフォーム運営）

- 事業内容: ポイント販売、プラットフォーム運営、プロジェクト管理
- 収益源: ポイント販売額の30%（手数料）
- 法的位置付け: デジタルコンテンツ / サービス利用権の販売事業者
- ポイントは自社プラットフォーム内でのみ使用可能な「サービス利用権」であり、法定通貨への換金・他者への譲渡は不可 → 資金決済法上の「前払式支払手段」に該当しない設計

### B社: 運営会社（業務委託元）

- 事業内容: クリエイター支援事業（業務委託の発注・検収・支払）
- 資金源: A社からの業務委託費 or 収益分配
- 法的位置付け: クリエイターに対する業務委託の発注者
- クリエイターとの間に業務委託契約を締結し、実務の対価として報酬を支払う

### クリエイター（業務受託者）

- 契約形態: B社との業務委託契約（個人事業主 or 法人）
- 受取金の性質: 業務委託報酬（源泉徴収対象）
- 納品義務: 契約に定められた実務の成果物を提出

---

## 資金フロー

```
ファン ──①ポイント購入（Stripe決済）──→ A社（FanUp）
                                            │
                                            │ ②業務委託費 or 収益分配
                                            ▼
                                         B社（運営会社）
                                            │
                                            │ ③業務委託報酬（銀行振込）
                                            ▼
                                        クリエイター
```

### ① ファン → A社: ポイント購入

- ファンがStripe決済でポイントを購入
- ポイントはFanUpプラットフォーム内の「応援」にのみ使用可能
- 購入時点でA社の売上として計上
- ファンはポイントを使ってプロジェクトを応援（ポイント消費）

### ② A社 → B社: 業務委託費 / 収益分配

- プロジェクト達成後、A社がB社に対して業務委託費を支払う
- 金額 = プロジェクト達成額 × 70%（A社手数料30%控除後）
- A社→B社間の契約形態は以下のいずれか:
  - 業務委託契約（B社がクリエイター支援業務をA社から受託）
  - 収益分配契約（プラットフォーム収益の一部をB社に分配）

### ③ B社 → クリエイター: 業務委託報酬

- B社がクリエイターに業務委託報酬として銀行振込
- 源泉徴収 10.21% を控除して支払い
- 支払調書を発行（確定申告用）

---

## 業務委託の実務内容（③の根拠）

三店方式の法的有効性の核心は、B社→クリエイター間の支払いに「実務」が伴うこと。形式的な契約だけでは税務上否認されるリスクがあるため、以下の具体的な業務を定義する。

### 業務委託契約の業務内容

1. **ファンクラブ開設準備**
   - 対象プラットフォーム（Fantia, FANBOX, Patreon等）でのアカウント作成
   - プロフィール設定、ヘッダー画像・アイコン作成
   - 料金プラン（ティア）の設計

2. **初期コンテンツ制作**
   - 開設時の投稿コンテンツ最低3本の制作
   - 限定コンテンツの企画書提出

3. **運営計画書の提出**
   - 3ヶ月間の投稿スケジュール
   - コンテンツカテゴリの設計
   - ファン獲得の施策案

4. **プラットフォーム設定**
   - 決済手段の設定
   - 通知・メール設定
   - 利用規約の確認・同意

### 納品物

- 開設済みファンクラブのURL
- 初期投稿3本以上（公開済み）
- 運営計画書（テンプレートあり）

### 検収フロー

1. クリエイターがFanUp上で「納品完了」を申請
2. B社が納品物を確認（URL有効性、コンテンツ数、計画書の記載）
3. 検収完了 → 5営業日以内に銀行振込

## 法的整理

### 資金決済法の回避

- ポイントは「自家型前払式支払手段」に該当しない設計:
  - 使用範囲がFanUpプラットフォーム内の「応援」のみ
  - 法定通貨への換金不可
  - 第三者への譲渡不可
  - 有効期限あり（購入から180日）
- ファン→クリエイター間の直接的な資金移動が存在しない
- A社は「資金移動業者」ではなく「サービス提供事業者」

### 特定商取引法

- ポイント販売は「電子商取引」に該当
- A社サイト上に特定商取引法に基づく表記を掲載

### 税務処理

| エンティティ | 収益/費用の性質 | 税務処理 |
|---|---|---|
| A社 | ポイント販売収益 | 売上計上、法人税課税 |
| A社 | B社への支払 | 業務委託費（経費） |
| B社 | A社からの受取 | 売上計上 |
| B社 | クリエイターへの支払 | 業務委託費（経費）、源泉徴収義務 |
| クリエイター | B社からの受取 | 事業所得（個人）or 売上（法人） |

### 消費税

- ファンのポイント購入: 課税取引（A社が納税）
- A社→B社: 課税取引
- B社→クリエイター: 課税取引（インボイス対応要）

---

## A社・B社間の関係に関する注意事項

### 同一代表の場合

A社とB社が同一代表者の場合、関連当事者取引として以下が必要:

- 取引価格の適正性の根拠（第三者間取引と同等であること）
- 各社の独立した意思決定の記録（取締役会議事録等）
- 移転価格税制への抵触がないことの確認

### 推奨構成

- B社は別代表 or 共同代表の別法人とするのが望ましい
- 最低限、B社に独立した事業実態（オフィス、従業員、取引先）があること
- B社の売上がA社からの収入のみにならないよう、他の事業も持つことが望ましい

## システム実装上の対応

### FanUpプラットフォーム側

- プロジェクト作成時にB社との業務委託契約（電子契約）への同意フローを実装
- 納品申請→検収→支払ステータスの管理機能
- クリエイターダッシュボードに支払明細・源泉徴収額の表示
- 支払調書の自動生成機能（年次）

### 利用規約への反映

- ポイントの性質（サービス利用権、換金不可、譲渡不可、有効期限）を明記
- クリエイターへの支払がB社からの業務委託報酬である旨を明記
- 納品義務と検収プロセスを明記

---

## リスクと対策

| リスク | 対策 |
|---|---|
| 税務当局に実態なし（ペーパー取引）と判断される | 業務委託に具体的な実務・納品物を付帯させる |
| B社の事業実態が不十分 | B社に他の事業も持たせ、独立した経営実態を確保 |
| ポイントが前払式支払手段と認定される | 換金不可・譲渡不可・使用範囲限定を厳格に運用 |
| 消費税のインボイス対応漏れ | クリエイターの適格請求書発行事業者登録を確認 |
| 源泉徴収漏れ | B社の支払システムで自動控除を実装 |
